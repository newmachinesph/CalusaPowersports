# Calusa Social Studio

1. Open `social-studio.html` in any browser (double-click works, no server needed).
2. Pick a template in the left sidebar, edit the text fields — the canvas updates live. Templates with imagery have a Photo dropdown.
3. Click **Download PNG** to save the full-resolution image (`calusa-<template>-<size>.png`).
